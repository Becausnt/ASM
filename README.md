# ASM-Experiments

Just me experimenting with programming directly in ASM.

Works with nasm and wsl. Compile script in `compile.sh` run `alias compile="full/path/to/compile.sh"` for usability and then run `compile file-to-compile.asm` to compile.


Following tutorials from [asmtutor](https://asmtutor.com/#lesson1) and [tutorialspoint](https://www.tutorialspoint.com/assembly_programming/assembly_basic_syntax.htm)

Just a small repo for personal experiments and fascination.
